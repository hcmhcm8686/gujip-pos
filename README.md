# 그집추어탕 주문·매출 앱

폰 하나로 테이블 주문을 받고, 결제를 누르면 매출이 기록되는 간단한 앱입니다.
갤럭시 노트10+ 같은 안드로이드 폰의 Chrome에서 열어 "홈 화면에 추가"하면 일반 앱처럼 쓸 수 있습니다.
인터넷이 끊겨도 동작합니다. 매출은 폰 안에 저장되고, 클라우드에 연결하면 Firebase에도 자동으로 저장됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 앱 본체 (화면, 주문·결제·매출 계산, 관리자 비밀번호) |
| `cloud.js` | 클라우드 자동 저장 (Firebase Firestore로 올리고 받아오기) |
| `firebase-config.js` | Firebase 웹 앱 설정값 (비어 있으면 폰 저장만 사용) |
| `firestore.rules` | Firestore 보안 규칙 (Firebase 콘솔에 붙여 넣는 내용) |
| `sw.js` | 오프라인 동작용 (인터넷 없이도 실행, Firebase SDK도 보관) |
| `manifest.json`, `icons/` | 홈 화면 아이콘과 앱 이름 |

## 사용법 (가게에서)

1. **테이블 화면**에서 손님이 앉은 테이블(또는 맨 위의 **포장**)을 누릅니다.
2. **메뉴를 누르면 담기고**, 아래 목록에서 −/+ 로 수량을 고칩니다. 다른 테이블로 갔다 와도 주문은 남아 있습니다.
3. 계산할 때 **결제하기 → 현금 또는 카드**를 누르면 끝입니다. 현금은 메뉴별 **현금가**(추어탕·제육정식 9,000원, 반계탕 10,000원)로 자동 계산되고, 소주·맥주·음료는 정가 그대로입니다.
4. 잘못 결제했으면 **매출 → 일 → 주문 내역**에서 **취소**를 누릅니다.
5. **매출** 탭에서 일/주/월/년을 고르고 ◀ ▶ 로 기간을 옮깁니다. "오늘"을 누르면 오늘로 돌아옵니다.
6. 메뉴·정가·현금가·테이블 이름과 인원은 **설정** 탭에서 바로 바꿀 수 있습니다.
7. 화면 색은 **설정 → 화면 스타일**에서 그린(기본)·오렌지·화이트·다크 중 고를 수 있습니다.

## 폰에 설치하기

앱 주소: **https://hcmhcm8686.github.io/gujip-pos/** (GitHub Pages, 무료)

1. 폰 Chrome에서 위 주소를 엽니다. (처음 한 번은 인터넷이 필요하고, 그 뒤로는 없어도 됩니다)
2. Chrome 메뉴(⋮) → **홈 화면에 추가** → 추가. 홈 화면 아이콘으로 열면 전체 화면 앱으로 뜹니다.
3. 폰 설정 → 디스플레이 → **화면 자동 꺼짐** 시간을 길게 잡아 두면 편합니다.

## 클라우드 자동 저장 (Firebase, 무료)

연결해 두면 결제·취소할 때마다 매출이 클라우드에도 저장됩니다. 폰이 고장 나도 새 폰에서 같은 계정으로 로그인하면 매출이 그대로 돌아오고, 다른 폰이나 PC에서도 같은 주소로 매출을 볼 수 있습니다. 인터넷이 끊기면 폰에 모아 두었다가 연결되면 올립니다.

### 처음 한 번 하는 설정 (관리자)

1. https://console.firebase.google.com 에 구글 계정으로 들어가 **프로젝트 만들기** → 이름 `gujip-pos` → Google 애널리틱스는 **사용 안 함** → 만들기. 요금제는 무료(Spark) 그대로 둡니다.
2. **Firestore Database** → 데이터베이스 만들기 → 에디션을 물으면 Standard → 위치 **asia-northeast3 (서울)** → **프로덕션 모드** → 만들기.
3. Firestore의 **규칙** 탭에 이 폴더의 `firestore.rules` 내용을 붙여 넣고 **게시**.
4. **Authentication** → 시작하기 → 로그인 방법에서 **이메일/비밀번호** 사용 설정 → 저장. **사용자** 탭 → 사용자 추가 → 가게 계정 이메일과 비밀번호(6자 이상)를 만듭니다.
5. Authentication → **설정** → 승인된 도메인 → `hcmhcm8686.github.io` 추가.
6. 프로젝트 개요 → **앱 추가 → 웹(</>)** → 닉네임 `gujip-pos` → 앱 등록(Firebase 호스팅은 체크하지 않음). 화면에 나오는 `firebaseConfig = { ... }` 값을 `firebase-config.js`의 `null` 자리에 넣고 GitHub에 올립니다.
7. 폰 앱을 두 번 다시 연 뒤 **설정 → 클라우드 자동 저장**에서 4번의 이메일·비밀번호로 로그인합니다. 처음 로그인하면 폰에 있던 매출이 모두 올라갑니다.

- `firebaseConfig` 값은 공개되어도 괜찮습니다. 데이터는 보안 규칙 때문에 로그인한 가게 계정만 읽고 쓸 수 있습니다. GitHub가 "API 키가 공개됐다"는 안내 메일을 보낼 수 있는데, Firebase 웹 설정값이라 정상입니다.
- 무료 한도(하루 쓰기 2만 건, 읽기 5만 건, 저장 1GB)는 이 가게 사용량보다 훨씬 커서 요금이 나오지 않습니다. 결제 수단을 등록하지 않으면 유료로 바뀌지도 않습니다.
- 클라우드에서 지운 기록은 실제로 지우지 않고 `deleted: true`로 표시만 합니다. 실수로 지운 기록은 Firebase 콘솔에서 되살릴 수 있습니다.

## 관리자 비밀번호

- **매출 기록 전체 삭제**와 **백업 파일 복원**은 관리자 비밀번호(숫자 4~8자리)를 입력해야 실행됩니다. 설정 → 관리자 비밀번호에서 정하거나 바꿉니다.
- 비밀번호를 잊었으면 입력 창의 **비밀번호를 잊었어요**를 누르고 클라우드 가게 계정 비밀번호로 확인한 뒤 새로 정합니다(클라우드에 로그인되어 있을 때).

## 데이터와 백업

- 매출의 원본은 폰 안의 브라우저 저장소(IndexedDB)입니다. 클라우드에 연결되어 있으면 같은 내용이 Firestore에도 있습니다.
- **백업 파일 내보내기**는 한 번 더 안전하게 보관하고 싶을 때 씁니다. **엑셀용(CSV) 내보내기**는 엑셀이나 구글 시트에서 열어 보는 용도입니다.
- 클라우드 없이 쓸 때는 폰 Chrome에서 "사이트 데이터 삭제"를 하면 매출도 지워지니 주의하세요.

## 수정·업데이트

코드를 고친 뒤 이 폴더에서 아래처럼 올리면, 폰에서 앱을 **두 번째 열 때부터** 새 버전이 적용됩니다.

```bash
git add -A
git commit -m "변경 내용"
git push
```

PC에서 미리 보려면 이 폴더에서 아래를 실행하고 브라우저에서 `http://localhost:8765` 를 엽니다.

```bash
python -m http.server 8765
```
