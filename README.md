# 그집추어탕 주문·매출 앱

폰 하나로 테이블 주문을 받고, 결제를 누르면 매출이 기록되는 간단한 앱입니다.
갤럭시 노트10+ 같은 안드로이드 폰의 Chrome에서 열어 "홈 화면에 추가"하면 일반 앱처럼 쓸 수 있습니다.
인터넷이 끊겨도 동작하고, 매출은 폰 안에 저장됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 앱 본체 (화면, 주문·결제·매출 계산) |
| `sw.js` | 오프라인 동작용 (인터넷 없이도 실행) |
| `manifest.json`, `icons/` | 홈 화면 아이콘과 앱 이름 |

## 사용법 (가게에서)

1. **테이블 화면**에서 손님이 앉은 테이블(또는 맨 위의 **포장**)을 누릅니다.
2. **메뉴를 누르면 담기고**, 아래 목록에서 −/+ 로 수량을 고칩니다. 다른 테이블로 갔다 와도 주문은 남아 있습니다.
3. 계산할 때 **결제하기 → 현금 또는 카드**를 누르면 끝입니다. 현금은 음식 메뉴만 10% 할인된 금액이 자동 계산되어 표시되고(소주·맥주·음료는 제외), 그 금액으로 기록됩니다.
4. 잘못 결제했으면 **매출 → 일 → 주문 내역**에서 **취소**를 누릅니다.
5. **매출** 탭에서 일/주/월/년을 고르고 ◀ ▶ 로 기간을 옮깁니다. "오늘"을 누르면 오늘로 돌아옵니다.
6. 메뉴·가격·테이블 이름·현금 할인율은 **설정** 탭에서 바로 바꿀 수 있습니다.

## 폰에 설치하기

앱 주소: **https://hcmhcm8686.github.io/gujip-pos/** (GitHub Pages, 무료)

1. 폰 Chrome에서 위 주소를 엽니다. (처음 한 번은 인터넷이 필요하고, 그 뒤로는 없어도 됩니다)
2. Chrome 메뉴(⋮) → **홈 화면에 추가** → 추가. 홈 화면 아이콘으로 열면 전체 화면 앱으로 뜹니다.
3. 폰 설정 → 디스플레이 → **화면 자동 꺼짐** 시간을 길게 잡아 두면 편합니다. (앱이 켜져 있는 동안은 앱이 화면을 켜 두려고 시도합니다)

코드를 고친 뒤 다시 올리는 방법 (PC, 이 폴더에서):

```bash
git add -A
git commit -m "변경 내용"
git push
```

GitHub 계정(hcmhcm8686)으로 `gh auth login` 이 되어 있어야 합니다. 저장소를 처음 만들 때는
`gh repo create gujip-pos --public --source=. --remote=origin --push` 를 실행하고, 저장소의 Settings → Pages 에서 main 브랜치를 선택합니다.

PC에서 미리 보려면 이 폴더에서 아래를 실행하고 브라우저에서 `http://localhost:8765` 를 엽니다.

```bash
python -m http.server 8765
```

## 데이터와 백업

- 매출은 폰 안의 브라우저 저장소(IndexedDB)에 저장됩니다. 인터넷이 필요 없습니다.
- **설정 → 데이터 → 백업 파일 내보내기**를 가끔 눌러 카카오톡 '나에게 보내기'나 구글 드라이브에 보관하세요. 폰을 바꾸면 **백업 파일 복원**으로 되살립니다.
- **엑셀용(CSV) 내보내기**는 엑셀이나 구글 시트에서 열어 보는 용도입니다.
- 주의: 폰 Chrome에서 "인터넷 사용 기록 삭제 → 사이트 데이터"를 지우면 매출도 함께 지워집니다. 홈 화면에 설치해 두면 지워질 위험이 줄어듭니다.

## 수정·업데이트

- 코드를 고친 뒤 GitHub에 다시 올리면, 폰에서 앱을 **두 번째 열 때부터** 새 버전이 적용됩니다.
- 저장 방식을 바꾸고 싶으면 `app.js`의 `DB` 객체만 교체하면 됩니다. (예: Firebase)

## 나중에 추가할 수 있는 것

- **Firebase(무료 플랜) 연동**: 매출을 클라우드에 자동 저장해서 본인 폰·PC에서도 보고, 폰이 고장 나도 안전하게.
- **진짜 APK 파일**: PWABuilder(pwabuilder.com)에 앱 주소를 넣으면 APK를 만들어 줍니다. PC에 Android 도구를 설치하지 않아도 됩니다.
